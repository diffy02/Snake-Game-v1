# 🐍 Classic Snake Game (Python)

Sebuah replika game klasik "Snake" yang dibangun menggunakan bahasa pemrograman Python. Proyek ini dibuat untuk mendemonstrasikan pemahaman tentang logika pemrograman, penanganan *input* secara *real-time*.

## ✨ Fitur Utama
- Kontrol Responsif: Pergerakan ular yang mulus menggunakan tombol panah pada *keyboard* (Up, Down, Left, Right).
- Sistem Skor: Skor otomatis bertambah setiap kali ular memakan makanan.
- Deteksi Tabrakan: Game otomatis berakhir (*Game Over*) jika ular menabrak dinding pembatas atau menabrak tubuhnya sendiri.
- Tampilan Sederhana & Bersih: Menggunakan visualisasi grafis minimalis yang nyaman dilihat.

## 🛠️ Tech Stack & Library
Proyek ini murni menggunakan Python dengan *library* bawaan (tidak perlu instalasi eksternal yang rumit):
- Python 3.13.3
- Turtle Graphics
